Milestone 7 hands-on checks

This page is served from your own computer. Nothing on it is dangerous. Result of each button is also written in the box at the bottom.

1. Downloads

Click each link. Then open the downloads panel (Ctrl+J).

  • notes.txt expect: downloads, shows "scanning", then can be opened.
  • invoice.pdf.exe expect: blocked, "নিরাপত্তার কারণে ব্লক করা হয়েছে", only a delete button.
  • photo.jpg.scr expect: blocked in the same way.
  • eicar.com (the standard harmless antivirus test string) expect: Windows Defender removes or blocks it, and Obhijatri does not let you open it.

2. Camera, microphone, location

Expect: a Bangla allow / deny prompt. Your choice is remembered for this site; press the button again and it should not ask again. Undo it in Settings, প্রাইভেসি, site permissions ("Remove"). (A PC without a camera or microphone may report an error after the prompt: that is fine.)

3. Notifications

Expect: no prompt. The request is denied quietly and a small bell icon appears in the toolbar. Click the bell and choose to allow; then ask again and it should be granted.
