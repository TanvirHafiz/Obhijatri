## Bijoy to Unicode converter (SutonnyMJ text on web pages)
- Files (MPL 2.0):
  - `src/Obhijatri.Bangla/Bijoy/BijoyMap.json`: the character tables (Bijoy codes to Unicode, before and after steps), generated from the Python source of the package below by a script and otherwise unchanged, except that one replacement string was corrected (`[ঃ` gives `[:`; the original leaves a stray backslash).
  - `src/Obhijatri.Bangla/Bijoy/BijoyConverter.cs`: C# port of the package's conversion and reordering algorithm. Two deliberate changes: the reph (র্) reordering guard, which the original has backwards (it left every reph after its syllable, so কর্ম came out as কমর্), and র + য-ফলা, which now becomes র + ZWJ + ্য so it is not read as a reph. Both are covered by tests in `tests/Obhijatri.Tests/BijoyConverterTests.cs`.
- Original: `bijoy2unicode` version 0.1.1 (Python), https://github.com/Mad-FOX/bijoy2unicode, MPL 2.0 (downloaded 2026-09-29, with the owner's approval). It follows earlier converters listed in its README: https://github.com/bahar/BijoyToUnicode and https://github.com/sh-sabbir/UnicodeToBijoy.
- License: Mozilla Public License 2.0, the same text as for Avro: `src/Obhijatri.Bangla/Phonetic/MPL-2.0.txt`.
- MPL 2.0 obligation: as for the Avro files, the source of `BijoyMap.json` and `BijoyConverter.cs`, including our changes, must be made available to everyone who receives Obhijatri.
- `tests/Fixtures/bijoy-cases.json` was generated by running the original package on Unicode Bangla words from our own word list and Avro test fixtures; it is test data.
